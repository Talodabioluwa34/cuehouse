# Naming Brief

- **Audience:** Media operators (primary), pastors, service coordinators; buyer often pastor/admin
- **Problem:** Multi-app scramble during live service; scripture/lyrics appear late
- **Outcome:** Service flows; screens keep up; booth stays calm
- **Positioning:** Control center for church service — not “church presentation software”
- **Personality:** Precise, calm under pressure, trustworthy, modern, accessible (volunteer-friendly), Africa-credible
- **Requirements:** Pronounceable in Nigerian English; searchable; distinct from Vestry; scalable beyond scripture-only; not US-church-cliché
- **Architecture:** Masterbrand for the company and product (not a feature name)

# Recommended Naming Territory

**Territory: Cue the house**

Own the moment the pastor calls and the room sees it. “House” = house of worship / the sanctuary. “Cue” = live operator language already used in production.

Avoid: Beam/light, Flow, Presenter, ChMS words (Vestry, Sanctuary-as-admin).

---

# Naming Directions

1. **Cue the house** — booth cues what the congregation sees *(preferred)*
2. **Keep pace with the pulpit** — media never lags the sermon
3. **Lectern / Word stand** — scripture put forward with dignity
4. **Call → screen** — literal pastor-call metaphor

# Detailed Analysis

## CUEHOUSE

**Architecture:** Suggestive + compound (Cue + House)  
**Core meaning:** Cue what the house sees  
**Strategic idea:** Live service control for the sanctuary — not slide software  
**Construction:** English compound; 2 stresses (CUE-house); easy spelling after one hear  
**Personality:** Operational, calm, modern, booth-native  
**Customer perception:** “That’s the thing we run Sunday from the media desk.”

**Strengths**
1. Matches positioning (control center), not category (presenter)
2. Escapes Beam / Flow / Presenter traps
3. Separates cleanly from Vestry (admin vs live)
4. Spawns product language: CueHouse Live, CueHouse Display, go Live in CueHouse
5. Works in Nigerian English booth talk

**Risks**
1. “Cue” crowded in live-production SaaS (Cuez, CueMaster) — phonetic adjacency, not same product
2. Domain/trademark UNVERIFIED — counsel required
3. Needs one-line clarification once: “CueHouse runs your service screens”
4. “House” can mean home-tech in other categories (HouseCue home apps exist in search noise)

**Expansion:** Masterbrand for live service OS (planning + live + multi-screen + later AI assist)  
**Visual:** Strong wordmark; house/mark can be abstract geometric, not a literal church clipart  
**Scale test:** Credible as “CueHouse is the control center for live church services” at $100M+ ambition  
**WOM test:** “We run Sundays on CueHouse.” — natural

**Risk colour:** **YELLOW**

# Why This Name Wins

1. **Strategic fit** — Names the job (cue the house), not the tired category (presenter/worship software).
2. **Competitive separation** — Escapes Beam/Pewbeam light metaphors and the Flow pile-up.
3. **Architecture with Vestry** — CueHouse (Sunday live) vs Vestry (church admin) is a clean pair if both brands ever sit in one portfolio.
4. **Operator language** — Media teams already think in cues; “house” grounds it in the sanctuary.
5. **Scale** — Survives expansion beyond scripture into full live service OS without renaming.

Not recommended because it “sounds nice.” Recommended because it owns the right idea in a crowded naming field.

---

# Risks Before Commitment

1. **Trademark counsel** — Nigeria + key export markets; search CueHouse / Cue House / Cue-House
2. **Domain** — Prefer cuehouse.com / .app / getcuehouse.com — **UNVERIFIED availability**
3. **Social handles** — Exact @cuehouse may be taken; plan modifiers
4. **Phase 0 say-test** — Ask 5 media operators: “What do you think CueHouse does?”
5. **Phonetic check** — Ensure it doesn’t collapse to “Q House” / “Cuehos” in local speech
